# 🍳 食遇日记

一个类似"食遇日记"风格的家庭食谱 App,支持发现博主食谱、一键复刻、我的菜卡、饮食日历和家庭协作。

## ✨ 功能特性

### 📚 学菜(发现页)
- 内置博主食谱库:村驴厨房、吕小厨、官方推荐
- 顶部横向博主筛选
- 分类标签:肉类、海鲜、素菜、面食、汤品、主食、凉菜、早餐、午餐、晚餐等
- 关键词搜索(菜名/食材)
- 食谱卡片展示食材/步骤摘要

### 📇 菜卡(我的食谱本)
- 从发现页一键"复刻"食谱到自己的菜卡
- 复刻后的食谱可自由编辑、删除
- 也可创建原创菜卡
- 标记"已复刻"或"原创"

### 📅 饮食日历
- 7 天日历视图
- 早中晚三餐安排
- 周末高亮
- 从菜卡或收藏中选择菜品加入日历

### 👨‍👩‍👧 家宴(家庭协作)
- 创建家庭,生成 6 位邀请码
- 家人输入邀请码加入
- 共享饮食日历(未来可扩展)

### 👤 我的
- 个人资料
- 菜卡/收藏/家宴统计
- 添加到主屏幕引导

## 📱 添加到 iPhone 主屏幕

1. 用 Safari 打开应用 URL
2. 点击底部分享按钮
3. 选择"添加到主屏幕"
4. 桌面出现"食遇日记"图标,点击全屏打开

## 🚀 部署

### 依赖
```bash
pip install -r requirements.txt
```

### 本地运行
```bash
python app.py
```

### 生产部署
支持 Render、Railway 等平台:
- Build: `pip install -r requirements.txt`
- Start: `gunicorn app:app --bind 0.0.0.0:$PORT`
